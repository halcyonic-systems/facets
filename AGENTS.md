# AGENTS.md

The short entry for any coding agent dropped into this clone. The full runbook is
[`CLAUDE.md`](CLAUDE.md); read it before changing anything. This page is what you
need in the first minute.

## What this is

Facets: a systems-modeling instrument. `crates/` (Rust, compiled to WebAssembly)
owns every verdict, all validation, and the run; `web/` (React) renders it;
`chat/` and `portal/` are the other two faces of the site at facets.systems.
**Any systems logic found in JavaScript is a bug.** The wasm surface
(`crates/bert-lenses-kernel/API.md`) is frozen and append-only.

## First commands

```bash
just preflight   # names any missing prerequisite and its install line
just check       # the full gate, in CI's order; green before every commit
just bert verdict assets/examples/predator-prey.sl --lens bunge   # ask the kernel from a shell
```

`just check` skips one gate locally: Lean citation resolution (Gate A) needs a
checkout of the `systems-science-foundations` repo at the commit pinned in
`docs/lean-manifest.json`; CI runs it. Two more gates run only in CI: the macOS
bundle and the licence/advisory check.

## Not in this clone

- **The Lean proofs.** `systems-science-foundations` is a separate repo. Claims
  in `docs/` cite it by `claim_id`; `docs/lean-provenance.md` maps them.
- **The reasoner.** Chat and the Model co-author call the General Systems
  Reasoner, a separate Python service (port 5010 locally; `api.facets.systems`
  hosted). Nothing in the kernel, the CLI, or the gates needs it.
- Any path under a home directory. If a doc points outside the repo, that is a
  doc bug; file it or fix it, do not hunt for the file.

## Do not touch

- The `live` branch and `_site/`: build output of `scripts/publish-site.sh`.
- `crates/*/pkg/`: wasm-pack output, regenerated by `just wasm`.
- `shared/frost.css`: generated from `web/src/index.css` by
  `scripts/gen-frost-shared.mjs`.
- Golden fixtures (`fixtures/cli/canonical.json`, the minted demo JSON) except
  through their bless variables (`BLESS_CLI_GOLDEN=1`, `BLESS_SL_DEMOS=1`), and
  only after reading the diff.
- The generated tables in `docs/lean-provenance.md` (`just provenance` rewrites them).

## Docs have rules

Every file under `docs/` and `spec/` carries exactly one status word and is
reachable from `docs/README.md`; `scripts/doc_lint.py` fails the build otherwise.
Root files (this one, `CONTRIBUTING.md`, `SECURITY.md`) need no status but their
relative links must resolve. How a proposal becomes a decision: `CONTRIBUTING.md`.
